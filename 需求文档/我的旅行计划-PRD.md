## 1. 功能概述

用户在"我的旅行计划"页面管理自己保存的旅行计划：浏览列表、查看详情、搜索、删除、复制分享。**以数据库已保存数据展示为主，AI 不重新生成行程内容**，仅辅助生成标题、摘要等轻量文案（可降级）。

- 未登录访问 → 跳转登录页（全局路由守卫，见《主页面-需求描述.md》）
- 主页"我的旅行计划"按钮接入本列表页（原"功能建设中"占位取消）

## 2. 功能列表

| # | 模块 | 概要 |
|---|---|---|
| 1 | 计划列表 | 每页 10 条，按保存时间倒序，展示 8 项字段 |
| 2 | 计划详情 | 结构同生成结果页 + 保存时间，含"导出 PDF"按钮（见《旅行计划PDF导出-PRD.md》） |
| 3 | 搜索筛选 | 关键词匹配标题 + 目的地，空关键词展示全部 |
| 4 | 排序 | 按保存时间倒序，不做切换 |
| 5 | 删除 | 二次确认"删除后不可恢复"，硬删除 |
| 6 | 分享/复制 | 复制纯文本（行程概览+每日安排）到剪贴板 |
| 7 | 空状态 | 无计划时引导去"生成旅行计划" |
| 8 | 加载与失败状态 | 加载失败可重试，数据为空有明确提示 |

## 3. 详细描述

### 3.1 计划列表

| 字段 | 来源 |
|---|---|
| 计划标题 | 保存时 AI 生成落库（降级规则见 3.6） |
| 目的地 | 生成条件 |
| 出行日期/天数 | 有出发日期显示日期区间，无则显示"X 天" |
| 人均预算 | 生成条件，显示"人均 ¥xxx" |
| 人数 | 生成条件 |
| 兴趣偏好标签 | 生成条件中的兴趣偏好，直接展示 |
| 保存时间 | 精确到分钟 |
| 缩略摘要 | 保存时 AI 生成落库（1-2 句，降级规则见 3.6） |
| 是否使用参考攻略 | 保存数据标记（不展示于列表），用于详情页免责声明口径 |

- 分页：每页 **10 条**，分页控件为数字页码 + 上/下一页并显示总条数；按保存时间**倒序**，不做正序切换
- 点击列表项 → 进入该计划详情页

### 3.2 搜索筛选

- 单个搜索框，关键词模糊匹配**计划标题 + 目的地**
- 关键词为空 → 展示全部计划
- 搜索无结果 → 提示"未找到匹配的计划"
- 搜索为前端触发、后端过滤，分页对搜索结果同样生效

### 3.3 计划详情

- 展示内容与《旅行计划生成-PRD.md》3.3 结果展示结构一致：**行程概览、每日安排、预算估算、注意事项、备选建议**，另显示**保存时间**；其中每日安排含景点提示、交通方式对比、附近美食等细化子结构（口径见《旅行计划生成-PRD.md》3.3.1）
- 展示的是保存时的计划快照，页面不做 AI 重新生成
- 操作按钮：**复制**（见 3.5）、**删除**（见 3.4）、**导出 PDF**（见《旅行计划PDF导出-PRD.md》）、**返回**列表
- 免责声明随内容一并展示（"行程与价格均为 AI 估算，信息非实时，出行前请自行核实"；保存数据含"是否使用参考攻略"标记，使用过攻略时追加"参考内容来自公开分享，可能过时或夸大"句）

### 3.4 删除

- 入口：列表项与详情页均提供"删除"按钮
- 二次确认弹窗文案："确定删除该计划吗？**删除后不可恢复**"（确认 / 取消）
- **硬删除**：确认后物理删除，不进回收站，不可恢复
- 数据归属：仅能删除**本人**的计划

### 3.5 分享/复制

- 点击"复制"→ 将**行程概览 + 每日安排**（含景点提示、交通方式对比、附近美食等子结构）整理为纯文本写入剪贴板 → toast"已复制"
- 复制内容**不含用户隐私**（用户名、邮箱等一律不包含）
- 复制内容末尾附免责声明一行

### 3.6 AI 辅助生成要求（本模块 AI 的角色边界）

| 项 | 要求 |
|---|---|
| 用途 | 仅为计划生成**简短标题、列表摘要**、分享文案、空状态引导文案；**AI 不重新生成、不修改行程内容** |
| 时机 | **保存计划时同步生成**（在保存请求内完成并落库，保存返回即有标题），列表/详情直接读库，不现场调用 |
| 风格 | 中文、简短、结构化 |
| 事实约束 | **AI 不可篡改用户已保存的行程事实**，仅做概括提炼 |
| 降级 | AI 失败时回退规则文案：标题="目的地 + 天数 + 日游"（如"昆明 5 日游"），摘要=行程概览首句截断（≤50 字）；**不阻塞列表和详情展示** |
| 成本 | 每条计划仅保存时调用一次，列表浏览零 token 消耗 |

### 3.7 空状态与加载状态

| 状态 | 展示 |
|---|---|
| 空状态（无任何计划） | "暂无旅行计划，去生成你的第一个行程吧" + 按钮"生成旅行计划"（跳转生成页） |
| 搜索无结果 | "未找到匹配的计划" |
| 加载中 | 骨架屏/loading 动画 |
| 加载失败 | "加载失败，请重试" + "重试"按钮 |
| 删除后列表刷新 | 删除成功 toast"已删除"，列表自动刷新；当页删空自动加载上一页 |

## 4. 业务规则汇总

- **登录校验**：未登录不可访问，走全局路由守卫
- **数据归属**：用户只能查看、删除自己的计划（后端按登录态过滤，接口级校验）
- **分页与排序**：每页 10 条，默认按保存时间倒序
- **搜索**：关键词为空时展示全部
- **删除**：二次确认 + 硬删除不可恢复
- **分享**：复制文本不含用户隐私；本期无公开链接，无分享权限问题
- **空状态**：引导去"生成旅行计划"
- **异常**：加载失败可重试，数据为空有明确提示

## 5. 异常场景与提示文案

| # | 场景 | 提示文案 | 时机 |
|---|---|---|---|
| 1 | 列表加载失败 | 加载失败，请重试 + 重试按钮 | 请求失败时 |
| 2 | 详情加载失败 | 加载失败，请重试 + 返回列表入口 | 请求失败时 |
| 3 | 搜索无结果 | 未找到匹配的计划 | 搜索返回空 |
| 4 | 删除确认 | 确定删除该计划吗？删除后不可恢复 | 点击删除时 |
| 5 | 删除失败 | 删除失败，请重试 | 删除请求失败时 |
| 6 | 复制失败 | 复制失败，请重试 | 剪贴板写入失败 |
| 7 | 网络/服务器异常 | 网络异常，请稍后重试（全局统一） | 请求失败时 |
| 8 | 越权访问他人计划 | 提示"无权访问"，返回列表 | 后端归属校验不通过 |

## 6. 验收标准

1. 未登录状态访问列表页/详情页，被路由守卫拦截并跳转登录页
2. 用户 A 登录后仅能看到自己的计划；构造用户 B 的计划 ID 直接请求详情/删除接口，返回无权访问
3. 保存 12 条计划时，列表第一页展示 10 条、第二页 2 条，且按保存时间倒序排列
4. 关键词"昆明"能同时命中标题含"昆明"和目的地为"昆明"的计划；清空关键词后展示全部
5. 点击删除弹出"删除后不可恢复"确认框；确认后该记录从列表消失且数据库中物理删除，无法再访问
6. 点击复制后剪贴板内容包含行程概览与每日安排，且不含用户名、邮箱等隐私信息
7. 无任何计划时展示空状态引导，点击"生成旅行计划"跳转生成页
8. 断网或后端异常时展示"加载失败，请重试"，点击重试可恢复加载
9. AI 标题生成失败的计划，列表展示规则标题"目的地+天数日游"，列表与详情正常展示不受阻塞
10. 详情页完整展示行程概览、每日安排、预算估算、注意事项、备选建议与保存时间，内容与保存时一致（无 AI 改写）

## 7. 非功能性需求

| 类别 | 要求 |
|---|---|
| 性能 | 列表分页查询响应 ≤1s；详情读取 ≤1s；AI 标题/摘要在保存请求内同步生成（目标 1-3s），失败降级为规则文案 |
| 安全 | 接口登录态校验；数据归属接口级校验（防越权 ID 遍历）；删除为物理删除需谨慎授权 |
| 隐私 | 复制/分享内容不含用户名、邮箱；列表不展示任何隐私字段 |
| AI 成本 | 仅保存时一次同步调用（计入保存响应，目标 1-3s）；失败降级为规则文案，不阻塞保存成功；列表浏览零 token |
| 可用性 | 空状态/失败态/无结果态均有明确文案与下一步动作 |

## 8. 边界约定（本期不做）

- 不做公开分享链接（免登录只读页）
- 不做回收站 / 软删除
- 不做排序切换（仅保存时间倒序）
- 不做 AI 标签生成（直接展示保存时的兴趣偏好）
- 不做行程内容全文搜索

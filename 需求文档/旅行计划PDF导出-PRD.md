## 1. 功能概述

用户对确认心意的旅行计划，可将其导出为**可视化、排版精美的 PDF 文档**，含目的地实景配图参考。

**模块定位：可选增值操作**——
- 独立模块、独立后端接口，与"计划生成"接口分离，便于单独控制超时与资源
- 不导出也完全不影响浏览、保存、查看计划
- **零 LLM 纯数据渲染**（v1.6）：不调用任何大模型。11 部分全部由已保存数据组装或规则生成——交通信息、住宿推荐直接复用生成时已落库的数据，行前准备清单按出行天数与季节规则生成，景点速查表由每日安排中的景点提示重组

## 2. 功能列表

| # | 模块 | 概要 |
|---|---|---|
| 1 | 入口与触发 | 一模块两入口：生成结果页（保存后出现）+ 计划详情页 |
| 2 | PDF 内容组装 | 11 部分：封面、行前准备清单、交通信息、行程总览、住宿推荐、每日安排、景点速查表、费用参考、注意事项、备选建议、免责声明；**全部复用保存数据或规则生成，不调用模型** |
| 3 | 图库配图 | 当前版本不实现，保留为后续可选增强 |
| 4 | 版权与参考标注 | 当前版本无图片，仅保留文字来源与免责标注 |
| 5 | 生成与下载 | 后端统一接口同步生成，30s 超时，即时下载 |
| 6 | 降级策略 | 配图失败降级无图版式，不阻断导出 |
| 7 | 重复导出 | 不限次数，不存档，每次即时重新生成 |

## 3. 详细描述

### 3.1 入口与触发

| 入口 | 出现时机 | 说明 |
|---|---|---|
| 生成结果页 | **保存成功后**出现"导出 PDF"按钮；重新生成后隐藏，重新保存后再次出现 | 保存 = 确认心意；未保存不显示（导出按已保存的计划 ID 工作），保证"导出内容 = 已保存内容" |
| 计划详情页 | 始终显示"导出 PDF"按钮 | 见《我的旅行计划-PRD.md》3.3 |

- 点击"导出 PDF"→ 按钮置 loading 并禁用（防重复点击）→ 后端生成 → 浏览器下载文件
- 生成期间页面停留原处，成功后 toast"导出成功"并触发下载

### 3.2 PDF 内容结构

版式：**A4 纵向文档式**，便于打印与长行程阅读。

| 部分 | 内容 |
|---|---|
| 封面 | 计划标题、目的地、出行日期/天数、人数、人均预算、导出日期 |
| 行前准备清单 | 证件与财务、衣物装备、洗护药品、电子设备四类清单（**按天数与出发季节规则生成，不调用模型**；出发日期未填时不区分季节） |
| 交通信息 | **复用保存的**往返与城际交通（路线、可选方式、时长、费用、推荐） |
| 行程总览 | 整体主题建议、天数概览、预算汇总 |
| 住宿推荐 | **复用保存的**住宿推荐（区域、酒店/类型、档次、价格、理由，按优先级排序） |
| 每日安排 | 按天分块，每日含时间块（上午/下午/晚间）的地点/活动、景点提示、交通方式对比、附近美食、餐饮、分项预算、备注（子结构复用保存数据，口径见《旅行计划生成-PRD.md》3.3.1） |
| 景点速查表 | 由每日安排中的景点提示**重组**（景点、建议时长、门票、最佳时段、预约）；**信息标注"以实际为准，出行前核实"** |
| 费用参考 | 分项（交通/住宿/餐饮/门票/其他）+ 汇总 |
| 注意事项 | 目的地通用层：天气提醒、安全提示、文化习俗，含目的地级避坑反馈（标注"来自旅行者反馈"）；景点专属提示与景点级踩雷反馈随每日安排对应条目展示 |
| 备选建议 | 全局层：同目的地可替换的景点/活动建议；当日层替换建议随每日安排对应天展示 |
| 免责声明 | 末页固定：“行程与价格均为 AI 估算，信息非实时，出行前请自行核实。参考内容来自公开分享，可能过时或夸大。”（**通用免责声明，无条件包含全部条目**，不因该计划是否使用参考攻略而变化） |

### 3.3 配图规则（当前版本不实现，以下为后续可选增强）

- **密度**：封面 1 张 + 每日行程 1 张（15 天计划最多 16 张）
- **来源**：免费授权图库 API（Unsplash/Pexels 类，具体选型在开发文档确定）
- **搜索词**：封面按"目的地"，每日按"目的地 + 当日主打景点"
- **标注**：每张图下方标注"图片来源：图库名 · 仅供参考"；封面/总览处再次提示"文中图片仅供参考"
- **已知局限**：图库按关键词返回，图与具体景点不一定精确匹配——此即"仅供参考"标注的原因，产品预期上接受

### 3.4 降级策略

| 失败点 | 处理 |
|---|---|
| 配图 / LLM（当前不实现） | 版本为零 LLM 纯数据渲染且不含配图，无此类降级路径；内容字段缺失时按空值容错，导出仍成功 |
| PDF 生成失败 / 超时（30s） | 提示"导出失败，请重试"/"导出超时，请重试"，可手动重试 |

### 3.5 重复导出与文件命名

- 允许**不限次数**导出，无频控（本期）
- **不存档**：每次即时生成即时下载，服务端不保留历史 PDF 文件；重复导出重新生成
- 文件命名：`目的地+天数日游_导出日期.pdf`（如 `昆明5日游_20261118.pdf`）；目的地仅保留中英文与数字，其余字符剔除，防止文件系统非法字符

### 3.6 权限与安全

- 接口登录态校验（未登录返回 401，前端跳登录页）
- 数据归属校验：仅能导出**本人**保存的计划，越权返回"无权访问"

## 4. 异常场景与提示文案

| # | 场景 | 提示文案 | 时机 |
|---|---|---|---|
| 1 | 导出超时（>30s） | 导出超时，请重试 | 后端超时 |
| 2 | PDF 生成失败 | 导出失败，请重试 | 后端异常 |
| 3 | 网络/服务器异常 | 网络异常，请稍后重试（全局统一） | 请求失败时 |
| 4 | 配图（当前不实现） | 不适用 |
| 5 | 越权导出他人计划 | 无权访问 | 归属校验不通过 |
| 6 | 生成中重复点击 | 按钮禁用，无提示 | 防重复提交 |

## 5. 验收标准

1. 生成结果页在保存成功前不显示"导出 PDF"按钮；保存成功后按钮出现且可点击
2. 计划详情页始终显示"导出 PDF"按钮，点击后可成功下载 PDF 文件
3. 导出的 PDF 包含 11 部分：封面、行程总览、交通信息、住宿推荐、每日安排、景点速查表、费用参考、注意事项、备选建议、行前准备清单、免责声明；内容与保存数据一致（交通、住宿、每日安排、预算、注意事项、备选建议均直接复用；行前准备与景点速查表由规则/数据重组生成）；版式为 A4 纵向
4. 当前版本不含配图，PDF 为纯文字版式（配图为后续可选增强）
5. 全程不发起任何 LLM / 图库请求（可通过网关或日志观测验证）
6. 导出耗时超过 30 秒时提示"导出超时，请重试"，重试可成功
7. 生成中按钮处于禁用状态，重复点击不触发第二次导出请求
8. 使用用户 A 的计划 ID 由用户 B 发起导出，返回"无权访问"
9. 对同一计划连续导出 2 次，均成功且文件名为规则格式；服务端无历史 PDF 残留
10. 未登录状态调用导出接口返回 401，前端跳转登录页
11. 内容字段缺失（如无住宿、无交通、空 plan_content）时导出仍成功，不出现 500

## 6. 非功能性需求

| 类别 | 要求 |
|---|---|
| 性能 | 同步生成上限 30s；纯数据渲染实测约 0.1s（含数据库读取与 PDF 渲染）；生成期间前端 loading 流畅 |
| 成本 | **零 token**（不调用任何大模型）；当前版本不调用图库 |
| 合规 | 免责声明固定末页；PDF 内不使用外部图片 |
| 安全 | 登录 + 归属双重校验；PDF 内容不含用户名、邮箱等隐私信息 |
| 可用性 | 失败文案具体可读，重试路径明确；内容缺失容错渲染 |

## 7. 边界约定（本期不做）

- 不做 PDF 服务端存档与历史下载列表（每次即时生成）
- 不做模板/样式自定义（固定 A4 纵向精美模板）
- 不做 LLM 增量生成与图库配图（v1.6 零 LLM 实现，配图为后续可选增强）
- 不做 PDF 加密、水印、批量导出
- 不做导出频控（后续如遇滥用再评估）

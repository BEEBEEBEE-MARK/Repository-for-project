# 用户登录 - 需求描述

> 版本：v1.1　|　日期：2026-11-19　|　状态：已确认
>
> 变更记录：v1.1 依据审核报告将锁定文案中性化并记录已知风险

## 1. 功能概述

用户通过登录页输入凭证登录系统。凭证支持 **用户名或邮箱**（单输入框自动识别），成功后跳转主页。支持"记住我"（7 天登录态保持）与"退出登录"。

关联说明：用户名、邮箱的唯一性及格式规则见《用户注册-需求描述.md》。

## 2. 字段规则

### 2.1 登录凭证（用户名/邮箱）

| 规则项 | 要求 |
|---|---|
| 形态 | 单输入框，placeholder 为"用户名 / 邮箱" |
| 识别规则 | 输入内容含 `@` 按邮箱匹配，否则按用户名匹配 |
| 校验 | 仅做非空校验，不做格式校验（格式错误统一走"用户名或密码错误"） |
| 空格处理 | 首尾空格自动去除 |

### 2.2 密码

| 规则项 | 要求 |
|---|---|
| 校验 | 仅做非空校验，不做格式校验 |
| 空格处理 | 不做 trim，精确匹配 |

## 3. 正常流程

1. 用户进入登录页（**已登录状态访问登录页，自动跳转主页**）
2. 输入凭证与密码，可选勾选"记住我"
3. 前端非空校验通过后提交，后端验证凭证
4. 登录成功 → 跳转主页
   - 未勾选"记住我"：登录态为会话级，关闭浏览器后失效
   - 勾选"记住我"：登录态保持 **7 天**
5. 登录页提供"去注册"入口，点击跳转注册页
6. **退出登录**：主页右上角用户区提供"退出登录"入口（与用户名并排直显），点击清除登录态并跳转登录页

## 4. 异常场景与提示文案

| # | 场景 | 提示文案 | 校验时机 |
|---|---|---|---|
| 1 | 凭证为空 | 请输入用户名 | 前端即时 |
| 2 | 密码为空 | 请输入密码 | 前端即时 |
| 3 | 凭证不存在或密码错误（**统一提示，不区分原因**） | 用户名或密码错误 | 后端 |
| 4 | 连续失败 5 次触发锁定 | 尝试次数过多，请 5 分钟后再试 | 后端 |
| 5 | 网络/服务器异常 | 网络异常，请稍后重试 | 提交失败时 |

## 5. 防撞库锁定机制

- 同一账号连续登录失败 **5 次**，锁定该账号 **5 分钟**
- 锁定期间登录请求一律拒绝并提示锁定文案，**即使密码正确也不放行**
- 锁定计时从第 5 次失败起算；锁定到期后恢复，失败计数重新累计
- 登录成功后，失败计数立即清零
- **已知风险留痕**：① 锁定文案已中性化（不直接暴露账号存在性），但攻击者仍可经响应差异侧面推断，接受现状；② 按账号维度锁定可被恶意利用锁死他人账号（拒绝服务），本期接受此风险；"账号 + IP 组合锁定"列为开发期评估项

## 6. 交互细节

- **防重复提交**：提交中按钮置为 loading 并禁用
- **失败后的表单状态**：密码框清空并自动聚焦，凭证输入框保留原值
- **密码可见性**：密码框提供"显示密码"切换（小眼睛图标）
- **错误提示位置**：显示在对应输入框下方
- **记住我**：登录页默认不勾选

## 7. 边界约定（本期不做）

- 不做"忘记密码 / 找回密码"（依赖邮箱真实性保障，待邮箱验证流程上线后一并考虑）
- 不做第三方登录 / 扫码登录
- 不做图形验证码（防撞库已由锁定机制覆盖）
